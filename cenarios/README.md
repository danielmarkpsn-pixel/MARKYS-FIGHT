# Cenários — MARKYS FIGHT

Envie nesta pasta os GIFs animados que serão utilizados como cenários das arenas.

## Convenção sugerida

- Um GIF por cenário, com nome simples, por exemplo `arena-cidade.gif`.
- Mantenha os arquivos GIF originais sem alterações.
- Registre cada cenário no arquivo `manifest.json`.
- Use caminhos relativos à pasta `cenarios/`.

**Importante:** a pasta está preparada para receber arquivos, mas a seleção e renderização dos GIFs no jogo ainda não estão integradas.
